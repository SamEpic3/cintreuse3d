# Simulateur de cintreuse 400 – 3D

Simulateur de cintreuse à levier (rayon 15/16 po, tube 3/8 po) pour les étudiants en électromécanique : cintrage, rotation du tube pour des coudes en 3 dimensions, marques, mesures et relevé.

En ligne : https://samepic3.github.io/cintreuse3d/

Fonctionne aussi hors ligne : ouvrir `index.html` dans un navigateur (le moteur 3D Three.js r160, licence MIT, est intégré au fichier).
