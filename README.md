# Simulateur de cintreuse 400 – 3D

Simulateur de cintreuse à levier (rayon 15/16 po, tube 3/8 po) pour les étudiants en électromécanique : cintrage, rotation du tube pour des coudes en 3 dimensions, marques, mesures et relevé.

En ligne : https://samepic3.github.io/cintreuse3d/

Fonctionne aussi hors ligne : ouvrir `index.html` dans un navigateur (le moteur 3D Three.js r160, licence MIT, est intégré au fichier).

## Installer comme application (PWA)

Sur https://samepic3.github.io/cintreuse3d/ :
- **Chrome / Edge (ordinateur, Android)** : icône « Installer » dans la barre d'adresse, ou menu ⋮ → Installer l'application / Ajouter à l'écran d'accueil.
- **iPhone / iPad (Safari)** : bouton Partager → « Sur l'écran d'accueil ».

Une fois ouverte une première fois, l'app fonctionne sans Internet.
Après une mise à jour du site, changer `VERSION` dans `sw.js` pour que les appareils récupèrent la nouvelle version.
